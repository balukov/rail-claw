# OpenClaw 2026.9.2 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move SnapClaw's pinned OpenClaw from 2026.5.27 to 2026.9.2 so that existing Railway deployments migrate on their first boot and fresh installs work, then release SnapClaw 0.10.0.

**Architecture:** Every change is an idempotent boot step or a CLI-argument rename inside the existing three server files; the only new module is `src/upgrade.ts`, a side-effect-free file holding the three pure helpers the tests cover. The state migration runs `openclaw doctor --fix --non-interactive` once per OpenClaw version, gated by a marker file on the volume. The Codex reinstall/root-ownership machinery is deleted outright because 9.2 bundles the plugin and refreshes volume copies itself.

**Tech Stack:** Node 24 (runtime and builder), TypeScript 5 compiled with `tsc`, Node's built-in `node --test` runner (no test dependencies), Docker, OpenClaw 2026.9.2 CLI.

**Spec:** `docs/superpowers/specs/2026-09-06-openclaw-2026.9.2-upgrade-design.md`

```ts
export function parseJsonTail(output: string): unknown | null {
  const start = output.indexOf("{");
  if (start < 0) return null;
  try {
    return JSON.parse(output.slice(start));
  } catch {
    return null;
  }
}

export function needsMigration(marker: string | null, current: string): boolean {
  const cur = current.trim();
  if (!cur) return false;
  return (marker ?? "").trim() !== cur;
}

export function countAuthProfiles(output: string): number {
  const parsed = parseJsonTail(output) as { profiles?: unknown } | null;
  return Array.isArray(parsed?.profiles) ? parsed.profiles.length : 0;
}

export function dashboardFragment(output: string): string | null {
  const parsed = parseJsonTail(output) as { browserUrl?: unknown } | null;
  if (typeof parsed?.browserUrl !== "string") return null;
  let hash: string;
  try {
    hash = new URL(parsed.browserUrl).hash;
  } catch {
    return null;
  }
  return hash.includes("bootstrapToken=") ? hash : null;
}
```

```ts
const VERSION_MARKER = path.join(STATE_DIR, "openclaw-version");

async function migrateState(): Promise<void> {
  const v = await runCmd("openclaw", ["--version"], 10_000);
  const current = v.code === 0 ? v.output.trim() : "";
  let marker: string | null = null;
  try {
    marker = fs.readFileSync(VERSION_MARKER, "utf8");
  } catch {}
  if (!needsMigration(marker, current)) return;

  console.log(`[gateway] ${current} — running state migration (doctor --fix)`);
  const r = await runCmd("openclaw", ["doctor", "--fix", "--non-interactive"], 300_000);
  if (r.code !== 0) {
    console.warn(`[gateway] doctor --fix exited ${r.code}:\n${redactSecrets(r.output)}`);
    return;
  }
  try {
    fs.writeFileSync(VERSION_MARKER, current, "utf8");
  } catch {}
  console.log("[gateway] state migration complete");
}
```

```markdown
## 0.10.0

- **OpenClaw 2026.5.27 → 2026.9.2.** Redeploy to pick it up. The first boot runs OpenClaw's own state migration (`openclaw doctor --fix --non-interactive`, about a minute on Railway) and records the OpenClaw version on the volume so it runs once per version, not per boot. The panel's **Open Web UI** button goes through `openclaw dashboard`'s single-use owner handoff instead: click it once in each browser and the Control UI is authorised, nothing to approve. Bookmarks of the bare domain show "pairing required" until you do.
- **ChatGPT login is provider `openai`.** OpenClaw removed the `openai-codex` provider; first-time onboarding and re-authentication use `openai`, and doctor rewrites existing `openai-codex/*` model refs to `openai/*` while keeping the Codex runtime. - **Telegram bot is added with `openclaw channels add`,** which enables the plugin as well as storing the token; `config set` alone stopped doing that in 9.x.
- **Removed the codex plugin reinstall, the root re-own and the sudo helper.** The 2026.9.2 image bundles codex, doctor refreshes any stale volume copy itself, and the ownership check accepts the running user. ChatGPT OAuth cannot serve embedding requests, so the default left `memory_search` reporting memory unavailable. Add an OpenAI API key and set the provider yourself to turn embeddings on. `update.checkOnStart` is off — SnapClaw pins the version.
- **Background model use is now on by default:** OpenClaw's doctor creates a 30-minute heartbeat monitor and a nightly memory consolidation job for the agent. Both spend turns on your ChatGPT quota. To stop the heartbeat: `openclaw config set agents.defaults.heartbeat.every 0m` from the panel terminal, then restart the gateway.
- Panel console: logs come from `openclaw logs --limit N --plain`; the config dump reads `openclaw.json` directly; doctor runs non-interactively. `npm test` runs the new helper tests on Node's built-in runner.
```
